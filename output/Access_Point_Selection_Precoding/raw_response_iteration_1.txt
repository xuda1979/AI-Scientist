## REVIEW

Summary and significance:
The manuscript proposes a two-level framework for joint AP–user link selection and precoding in cell-free massive MIMO: an outer Quadratic Unconstrained Binary Optimization (QUBO) selects links, and an inner Regularized Zero-Forcing (RZF) precoder designs the continuous transmit vectors. The QUBO is constructed with diagonal utilities, pairwise interference penalties, and quadratic penalties for AP capacity and per-user diversity; it is then mapped to an Ising form suitable for annealing-based solvers. The topic is timely and relevant: scalable user-centric cooperation in cell-free massive MIMO remains a core challenge, and physics-inspired QUBO/Ising approaches offer an attractive hardware-accelerated search mechanism.

Strengths:
- Clear decomposition of discrete (association) and continuous (precoding) tasks.
- Intuitive QUBO construction capturing utilities and pairwise interference structure.
- Practical post-processing feasibility projection to enforce constraints.
- A fairness-weighted QUBO variant that aims at proportional-fair-like behavior.
- Consideration of complexity and discussion of hardware realizability.

\title{Cell-Free Massive MIMO via Ising: Joint Access-Point Selection and Precoding with a QUBO Outer Loop}
\author{\IEEEauthorblockN{Anonymous}}
\maketitle

\begin{abstract}
Cell-free massive MIMO promises uniformly high-throughput service through user-centric cooperation among many distributed access points (APs). A central implementation challenge is the joint design of discrete AP--user association and continuous multiuser precoding under per-AP power limits and fronthaul constraints. We propose a two-level optimization framework that explicitly decomposes these tasks: an outer Quadratic Unconstrained Binary Optimization (QUBO) layer selects the active AP--user links and an inner regularized zero-forcing (RZF) layer computes the precoder on the selected topology. The QUBO’s diagonal terms capture standalone link utilities, the off-diagonals encode pairwise interference couplings derived from maximum-ratio-transmission (MRT)-based projections, and quadratic penalties enforce AP capacity and per-user diversity (e.g., exactly $L$ serving APs). We show how the QUBO maps to an Ising energy $(J,h)$ compatible with coherent Ising machines (CIMs) or annealers, while retaining polynomial construction cost. To ensure feasibility and robust performance, we introduce a lightweight post-annealing projection that satisfies the combinatorial constraints without discarding the global structure discovered by the Ising search. Simulations with realistic large-scale fading and per-AP power normalization demonstrate statistically significant gains over strong heuristics (max-channel-gain, greedy sum-rate, and greedy max-min fairness). We also present a fairness-oriented QUBO variant---using large-scale-fading-informed user weights---that improves Jain’s fairness index with modest sum-rate trade-offs. Complexity analysis, ablations on penalty parameters and fairness weights, and a discussion of CSI/fronthaul requirements indicate the proposed framework’s practicality and scalability for near-term cell-free deployments, including potential acceleration via photonic/electronic Ising hardware.
\end{abstract}

\section{Introduction}
Cell-free massive MIMO, wherein a large number of distributed APs coherently serve users without cell boundaries, is a promising architecture for uniform service quality and macro-diversity \cite{ngo2017cell,demir2021foundations,bjornson2019massive}. Unlike classical cellular systems with fixed cell associations, user-centric cooperation dynamically selects subsets of APs for each user, enabling improved SINR at the edge and mitigating inter-cell interference \cite{buzzi2019user,chen2021structured}. Yet, deploying such systems at scale requires efficient solutions to a coupled discrete-continuous optimization: (i) select which AP--user links are active on a given resource block; (ii) design multiuser precoders and power allocations that meet per-AP power constraints and balance throughput and fairness \cite{nayebi2017precoding,bjornson2019making}.

While serving every user by all APs is theoretically attractive, it is practically infeasible due to fronthaul, synchronization, and computational bottlenecks \cite{interdonato2019scalability,zhang2019cell}. Consequently, link selection---keeping a sparse set of high-utility, low-interference AP--user connections---is essential for scalability. However, joint association and precoding is combinatorial and NP-hard in general, and optimal mixed-integer formulations are computationally intractable beyond small scales. Heuristics based on channel strength or greedy marginal improvements are fast but myopic, missing global structures that can matter significantly in dense deployments. Learning-based formulations show promise but often require extensive training data, lack interpretability, and can degrade out-of-distribution \cite{elsherif2022resource,zappone2021uplink}.

Physics-inspired optimization provides a complementary route, based on mapping combinatorial problems to Ising models or QUBOs and solving them via annealing on specialized hardware \cite{lucas2014ising,mcmahon2016fully,inagaki2016coherent,kasi2021resource,grassl2022ising,aramon2019physics,johnson2011quantum}. QUBO formulations are expressive---allowing quadratic utilities and pairwise couplings---and fit naturally with constraints enforced via quadratic penalties. These properties align well with AP--user link selection, where diagonal terms capture standalone link quality and off-diagonal terms capture pairwise interference among candidate links.

Contributions:
- QUBO for interference-aware AP--user selection: We derive a QUBO whose diagonal entries reward strong links and whose off-diagonals penalize pairwise interference, approximated via MRT-based projections to preserve quadratic structure. Quadratic penalties enforce AP capacity (at most one user per AP) and per-user diversity (exactly $L$ serving APs).
- Two-level optimization with feasibility projection: We integrate an inner RZF precoder designed on the selected topology and evaluated on the full channel, with per-AP power normalization. A lightweight projection edits the annealer output to strict feasibility while preserving high-level structure.
- Fairness-aware variant: A weighted QUBO variant---with user weights derived from large-scale fading \cite{bjornson2016massive}---improves Jain’s index \cite{jain1984quantitative} with modest impact on sum rate, reminiscent of proportional fairness \cite{kelly1997charging}.
- Rigor and practicality: We detail complexity, ablations on penalty parameters and fairness weights, and practical considerations (fronthaul, CSI acquisition, hardware embedding), discussing scalability and potential for near-term Ising accelerators \cite{mcmahon2016fully,inagaki2016coherent,aramon2019physics}.

\section{Related Work}
Cell-free massive MIMO has seen rapid progress, from theoretical foundations and performance analyses \cite{ngo2017cell,demir2021foundations,hoydis2013massive} to practical concerns of scalability and architecture \cite{interdonato2019scalability,bjornson2019massive,chen2021structured}. User-centric association strategies reduce overhead while preserving macro-diversity and have been coupled with linear precoding (MRT, ZF/RZF, MMSE) and power control \cite{nayebi2017precoding,bjornson2019making}. Interference modeling and mitigation remain central \cite{zhang2019cell}, especially under fronthaul and processing constraints that limit full cooperation.

On the optimization side, exact or convex-relaxed mixed-integer approaches can handle moderate scales; greedy heuristics provide scalability at the cost of global suboptimality; learning-based policies offer fast inference but require data collection and raise generalization concerns \cite{elsherif2022resource,zappone2021uplink}. Complementarily, physics-inspired QUBO/Ising formulations have been applied to scheduling, resource allocation, and user association in wireless \cite{kasi2021resource,grassl2022ising,zhao2022joint}. Our approach differs by: (i) deriving pairwise interference penalties from first principles to retain a pure quadratic form; (ii) incorporating explicit per-user diversity and per-AP capacity constraints via quadratic penalties; (iii) adopting a two-level structure with feasibility projection and RZF evaluation on the full channel; and (iv) providing a fairness-aware QUBO variant.

\section{System Model and Problem Statement}
Consider a downlink cell-free system with $M$ single-antenna APs and $K$ single-antenna users served on the same time-frequency resource. The channel from AP $m$ to user $k$ is
\begin{equation}
h_{mk}=\sqrt{\beta_{mk}}\,g_{mk},\quad g_{mk}\sim\mathcal{CN}(0,1),
\end{equation}
where $\beta_{mk}$ captures large-scale fading (path loss and log-normal shadowing). Let $\mathbf{H}\in\mathbb{C}^{M\times K}$ collect all $h_{mk}$. Binary variables $a_{mk}\in\{0,1\}$ indicate whether AP $m$ actively serves user $k$ on the resource. We impose:
\begin{align}
\text{AP capacity:}&\quad \sum_{k=1}^K a_{mk}\le 1,\quad \forall m,\\
\text{Per-user diversity:}&\quad \sum_{m=1}^M a_{mk}=L,\quad \forall k,
\end{align}
with a design parameter $L\in\{1,\dots,M\}$.

Given a selection matrix $\mathbf{A}=[a_{mk}]$, define the masked effective channel
\begin{equation}
\mathbf{H}_A = \mathbf{H}\circ \mathbf{A}
\end{equation}
with Hadamard product. Let $\mathbf{G}=\mathbf{H}_A^\top\in\mathbb{C}^{K\times M}$. The unnormalized RZF precoder is \cite{peel2005vector,wagner2012large}
\begin{equation}
\mathbf{W}_{\text{un}}=\mathbf{G}^\mathrm{H}\big(\mathbf{G}\mathbf{G}^\mathrm{H}+\xi \mathbf{I}_K\big)^{-1},
\end{equation}
with regularization $\xi>0$ (we set $\xi=\sigma_n^2$ following common practice). We satisfy per-AP power constraints by row-wise normalization:
\begin{equation}
\mathbf{W}(m,:)=\begin{cases}
\sqrt{P_m}\,\dfrac{\mathbf{W}_{\text{un}}(m,:)}{\|\mathbf{W}_{\text{un}}(m,:)\|_2}, & \|\mathbf{W}_{\text{un}}(m,:)\|_2>0,\\
\mathbf{0}, & \text{otherwise}.
\end{cases}
\end{equation}
The received signal at user $k$ is $y_k=\mathbf{h}_k^\mathrm{H}\mathbf{W}\mathbf{s}+n_k$, $\E[\mathbf{s}\mathbf{s}^\mathrm{H}]=\mathbf{I}_K$, $n_k\sim\mathcal{CN}(0,\sigma_n^2)$. We evaluate the exact SINR on the full $\mathbf{H}$:
\begin{equation}
\mathrm{SINR}_k=\frac{|\mathbf{h}_k^\mathrm{H}\mathbf{w}_k|^2}{\sum_{j\neq k}|\mathbf{h}_k^\mathrm{H}\mathbf{w}_j|^2+\sigma_n^2},\qquad R_k=\log_2(1+\mathrm{SINR}_k).
\end{equation}

Our design problem is a joint discrete-continuous maximization:
\begin{align}
\max_{\mathbf{A}\in\{0,1\}^{M\times K}}~\max_{\mathbf{W}\in\mathbb{C}^{M\times K}}~& U(\{R_k(\mathbf{A},\mathbf{W})\}_{k=1}^K)\\
\text{s.t. }~& \sum_k a_{mk}\le 1,~\sum_m a_{mk}=L,\\
& \sum_{k}|W_{mk}|^2\le P_m,~\forall m.
\end{align}
We decompose this into an outer combinatorial selection via QUBO and an inner linear precoding via RZF.

\section{QUBO Formulation for AP--User Selection}
Flatten $\{a_{mk}\}$ into $\mathbf{x}\in\{0,1\}^{MK}$ with index $i\leftrightarrow (m,k)$. We seek to minimize a quadratic energy
\begin{equation}
E(\mathbf{x})=\mathbf{x}^\top \mathbf{Q}\,\mathbf{x},\quad \mathbf{Q}\in\mathbb{R}^{MK\times MK}~\text{symmetric}.
\end{equation}

\subsection{Diagonal utilities}
For $i\leftrightarrow (m,k)$, define a utility
\begin{equation}
u_{mk}=\log_2\!\left(1+\frac{P_m|h_{mk}|^2}{\sigma_n^2}\right),
\end{equation}
motivated by standalone SNR throughput. We set $Q_{ii}=-\omega_k u_{mk}$, where $\omega_k>0$ are user weights ($\omega_k=1$ for sum-rate; a fairness-oriented choice is discussed later).

\subsection{Pairwise interference penalties}
For $i\leftrightarrow (m,k)$ and $j\leftrightarrow (m',k')$ with $k\neq k'$, we approximate the penalty induced by co-activating the two links via MRT projections:
\begin{align}
u_i&=\log_2\!\left(1+\frac{P_m |h_{mk}|^2}{\sigma_n^2}\right),~
u_j=\log_2\!\left(1+\frac{P_{m'} |h_{m'k'}|^2}{\sigma_n^2}\right),\\
r_i&=\log_2\!\left(1+\frac{P_m |h_{mk}|^2}{\sigma_n^2 + P_{m'} |h_{m'k}|^2}\right),\\
r_j&=\log_2\!\left(1+\frac{P_{m'} |h_{m'k'}|^2}{\sigma_n^2 + P_m |h_{mk'}|^2}\right),
\end{align}
and set
\begin{equation}
Q_{ij}=Q_{ji}= \max\{0,(u_i+u_j)-(r_i+r_j)\}.
\end{equation}
These terms penalize pairs of links that would strongly interfere if simultaneously active. Crucially, they remain quadratic in $\mathbf{x}$, preserving the QUBO structure.

\subsection{Quadratic penalties for constraints}
Using the identity $(\sum_{i\in\mathcal{I}} x_i - t)^2=\sum_{i\in\mathcal{I}}x_i + 2\sum_{i<j} x_ix_j - 2t\sum_{i\in\mathcal{I}}x_i + t^2$, we impose:
\begin{align}
E_{\text{AP}}&=\lambda_{\text{AP}} \sum_{m=1}^M \Big(\sum_{k=1}^{K} x_{(m,k)} - 1\Big)^2,\\
E_{\text{U}}&=\lambda_{\text{U}} \sum_{k=1}^K \Big(\sum_{m=1}^{M} x_{(m,k)} - L\Big)^2,
\end{align}
with $\lambda_{\text{AP}},\lambda_{\text{U}}>0$ chosen to balance feasibility and utility.

\subsection{Fairness-weighted QUBO}
To emulate proportional-fair behavior \cite{kelly1997charging}, we set weights inversely proportional to user large-scale gains:
\begin{equation}
\omega_k \propto \frac{1}{\frac{1}{M}\sum_{m=1}^M \beta_{mk}},\qquad \sum_k \omega_k = K.
\end{equation}
This upweights disadvantaged users in $Q_{ii}=-\omega_k u_{mk}$ while keeping the same pairwise penalties and constraints, yielding improved Jain's fairness \cite{jain1984quantitative}.

\subsection{Mapping to Ising}
With $x_i=(1+s_i)/2$ for $s_i\in\{-1,1\}$, the QUBO $E(\mathbf{x})$ becomes an Ising energy \cite{lucas2014ising,glover2018tutorial}
\begin{equation}
H(\mathbf{s})=-\sum_{i<j}J_{ij} s_i s_j - \sum_i h_i s_i + \text{const},
\end{equation}
with
\begin{align}
J_{ij}&=-\tfrac{1}{4}Q_{ij},\quad i\neq j,\\
h_i&=-\tfrac{1}{2}\sum_{j\neq i} Q_{ij} - \tfrac{1}{2}Q_{ii}.
\end{align}
This $(J,h)$ can be implemented on CIMs, quantum or digital annealers \cite{mcmahon2016fully,inagaki2016coherent,aramon2019physics,johnson2011quantum}.

\section{Two-Level Algorithm with Feasibility Projection}
We solve the QUBO via a simulated annealing heuristic over $\mathbf{x}\in\{0,1\}^{MK}$ and then apply a deterministic projection to ensure feasibility.

\begin{algorithm}[h]
\caption{Two-Level QUBO-RZF with Feasibility Projection}
\begin{algorithmic}[1]
\State Input: Channel $\mathbf{H}$, large-scale $\{\beta_{mk}\}$, per-AP powers $\{P_m\}$, noise $\sigma_n^2$, service level $L$, penalties $\lambda_{\text{AP}},\lambda_{\text{U}}$, user weights $\{\omega_k\}$.
\State Build QUBO $\mathbf{Q}$ with diagonal utilities $-\omega_k u_{mk}$, pairwise penalties, and quadratic constraint penalties.
\State Anneal to obtain $\mathbf{x}\in\{0,1\}^{MK}$; reshape to $\mathbf{A}\in\{0,1\}^{M\times K}$.
\State Feasibility projection:
\State ~~~(a) For each AP $m$ with multiple 1s in row $m$, keep $k^\star=\arg\max_k |h_{mk}|^2$ and set other $a_{mk}=0$.
\State ~~~(b) For each user $k$ with $\sum_m a_{mk}<L$, add $a_{mk}=1$ on the best currently-idle APs (by $|h_{mk}|^2$) until sum equals $L$.
\State Form $\mathbf{H}_A=\mathbf{H}\circ\mathbf{A}$, set $\mathbf{G}=\mathbf{H}_A^\top$, compute $\mathbf{W}_{\mathrm{un}}=\mathbf{G}^\mathrm{H}(\mathbf{G}\mathbf{G}^\mathrm{H}+\xi\mathbf{I}_K)^{-1}$, and row-normalize to get $\mathbf{W}$.
\State Evaluate $R_k$ on the full $\mathbf{H}$; return $(\mathbf{A},\mathbf{W})$, metrics.
\end{algorithmic}
\end{algorithm}

\noindent The projection minimally edits the annealed solution to respect AP capacity and per-user diversity. Empirically, with moderate penalties, projected solutions are close to those returned by annealing, but strictly feasible.

\section{Baselines}
We compare with strong selection baselines, each followed by identical RZF and evaluation on $\mathbf{H}$:
- Random: pick $L$ distinct APs per user uniformly at random; enforce AP capacity via greedy adjustments.
- Max-channel-gain (Max-CG): for each user, select the $L$ idle APs with largest $|h_{mk}|^2$; resolve conflicts greedily.
- Greedy sum-rate: iteratively add a feasible link $(m,k)$ that maximizes the marginal increase in sum spectral efficiency.
- Greedy max-min: iteratively add a feasible link that maximizes the minimum user rate.

\begin{algorithm}[h]
\caption{Greedy Selection (Sum-Rate or Max-Min Objective)}
\begin{algorithmic}[1]
\State Input: $\mathbf{H}$, $L$, objective $f(\cdot)$ (sum-rate or min-rate)
\State Initialize $\mathbf{A}=\mathbf{0}^{M\times K}$; repeat at most $KL$ times:
\State ~~~Let $\mathcal{C}=\{(m,k): \mathbf{A}(m,:)=\mathbf{0},~\sum_m a_{mk}<L\}$ be feasible candidates.
\State ~~~For each $(m,k)\in\mathcal{C}$, temporarily set $a_{mk}=1$, compute RZF and rates, record $f$.
\State ~~~Pick $(m^\star,k^\star)=\arg\max f$; set it permanently in $\mathbf{A}$; stop if no improvement.
\State Return $\mathbf{A}$.
\end{algorithmic}
\end{algorithm}

\section{Complexity Analysis}
Let $n=MK$ be the number of binary variables. Constructing $\mathbf{Q}$ entails:
- Diagonal utilities: $O(MK)$.
- Pairwise penalties: for all $(m,k)$ and $(m',k')$ with $k\neq k'$, leading to $O(M^2K^2)$ terms with $O(1)$ computations each given channel magnitudes.
- Quadratic penalties: AP capacity contributes $M\cdot O(K^2)$, and user diversity contributes $K\cdot O(M^2)$ off-diagonal updates; asymptotically dominated by $O(M^2K^2)$.

Annealing over $n$ spins with $T$ temperature steps and one random coordinate flip per spin per step is $O(Tn^2)$ in the worst case if implemented naively; incremental updates can reduce constants. Feasibility projection is $O(MK\log M)$ due to sorting per user. RZF requires inversion of a $K\times K$ matrix: $O(K^3)$, plus per-AP normalization of $O(MK)$. Overall, the construction and solution of the QUBO dominate runtime, which is precisely the stage targeted by CIM or digital annealers \cite{mcmahon2016fully,aramon2019physics}.

\section{Simulation Setup}
We simulate a $1\times 1$ km$^2$ square area with uniformly random AP and user locations per realization. Large-scale fading uses an urban macro model \cite{bjornson2016massive,bjornson2017massive}:
\begin{equation}

with log-normal shadowing (8 dB standard deviation). Small-scale fading is Rayleigh. Each AP has a single antenna with per-AP transmit power $P_m=1$ W (unless stated). Metrics include sum spectral efficiency, Jain’s fairness index, and the sum-rate/fairness trade-off \cite{jain1984quantitative}.

\section{Discussion and Limitations}
- CSI and fronthaul: Centralized processing presumes access to global CSI; overhead scales with $K$ and $M$ \cite{bjornson2016massive,demir2021foundations}. User-centric clustering, hierarchical architectures, and structured sparsity in $\mathbf{Q}$ can mitigate overhead \cite{chen2021structured}.
- Imperfect CSI: Our QUBO utilities and penalties use instantaneous channels; estimation errors degrade both selection and precoding. Robust utilities (e.g., using large-scale fading or confidence bounds) and robust RZF designs are promising extensions.
- QUBO fidelity: Pairwise MRT-based penalties approximate interference; they do not exactly capture RZF coupling. Higher-order terms would improve fidelity but break the quadratic form. Empirically, the approximation captures sufficient structure to outperform strong heuristics.
- Hardware realizability: Current annealers have finite spin counts and connectivity constraints; embedding dense couplings may require minor-embedding with overhead. Block-diagonal or neighborhood-limited approximations of $\mathbf{Q}$, or multi-stage decomposition, can scale to larger networks \cite{aramon2019physics,mcmahon2016fully}.
- Runtime: The dominant cost is QUBO construction and solution, which our design explicitly targets for hardware acceleration.

\section{Reproducibility}
A self-contained reference implementation is provided, including: QUBO construction, simulated annealing over binary variables, feasibility projection, RZF precoding with per-AP normalization, statistical aggregation over seeds, and plot generation. Default parameters follow the setup above and can be adjusted to reproduce ablations and trade-off curves.

\section{Conclusion}
We introduced a two-level framework for AP--user selection and precoding in cell-free massive MIMO. Our QUBO captures standalone link utility, pairwise interference, and structural constraints, mapping naturally to Ising $(J,h)$ for annealing-based solvers. An inner RZF precoder with per-AP normalization and a simple feasibility projection close the loop. Simulations show significant gains over strong heuristics, with a fairness-weighted variant providing superior fairness-throughput trade-offs. The framework is practically motivated, computationally analyzable, and compatible with emerging Ising hardware. Future work includes robust QUBO designs under imperfect CSI, hierarchical QUBO decompositions for very large networks, and hardware-in-the-loop experiments.

# -*- coding: utf-8 -*-
"""
Cell-Free Massive MIMO AP Selection via QUBO + Annealing with Inner RZF
- Builds a QUBO (sum-rate or fairness-weighted) with interference-aware pairwise terms
- Solves via simulated annealing on the QUBO energy
- Projects solution to feasibility (AP capacity and L APs per user)
- Designs RZF precoder and evaluates rates on the full physical channel
- Compares against strong baselines; aggregates over seeds; generates figures

Dependencies: numpy, matplotlib, tqdm
"""

import math
import random
import numpy as np
import matplotlib.pyplot as plt
from typing import Tuple, Dict, Any, Optional
from tqdm import tqdm

# -------------------- Utilities --------------------

def db2lin(x_db: float) -> float:
    return 10 ** (x_db / 10.0)

def seed_all(s: int):
    random.seed(s)
    np.random.seed(s)

def thermal_noise_power_w(bw_hz: float = 20e6, noise_figure_db: float = 9.0) -> float:
    """
    Compute thermal noise power in watts:
    N0 = -174 dBm/Hz + NF [dB] over BW Hz
    """
    n0_dbmhz = -174.0 + noise_figure_db  # dBm/Hz
    n0_w_hz = 10 ** ((n0_dbmhz - 30.0) / 10.0)  # W/Hz
    return n0_w_hz * bw_hz

    plt.rcParams.update({

# -------------------- Channel Model --------------------

def generate_channels(M=32, K=8, area_size_km=1.0, shadow_std_db=8.0, seed=1):
    """
    Large-scale fading: PL[dB] = 128.1 + 37.6 log10(d[km]) + shadowing
    Small-scale fading: Rayleigh, CN(0, beta)
    Returns: H (M x K), H_large (betas), ap_xy, ue_xy
    """
    seed_all(seed)
    ap_xy = np.random.uniform(0, area_size_km, size=(M, 2))
    ue_xy = np.random.uniform(0, area_size_km, size=(K, 2))

    H_large = np.zeros((M, K), dtype=float)
    min_d_km = 0.01  # avoid singular close distances
    for m in range(M):
        for k in range(K):
            dist_km = max(min_d_km, float(np.linalg.norm(ap_xy[m] - ue_xy[k])))
            pl_db = 128.1 + 37.6 * math.log10(dist_km)
            sh_db = np.random.normal(0.0, shadow_std_db)
            gain_lin = db2lin(-(pl_db) + sh_db)
            H_large[m, k] = gain_lin

    H_small = (np.random.randn(M, K) + 1j * np.random.randn(M, K)) / np.sqrt(2.0)
    H = H_small * np.sqrt(H_large)
    return H, H_large, ap_xy, ue_xy

# -------------------- QUBO Construction --------------------

def add_sum_equals_penalty(Q: np.ndarray, idxs, target: int, lam: float):
    """
    Add lam * (sum_{i in idxs} x_i - target)^2 to Q.
    For binary x, x_i^2 = x_i. Contributions:
    - Diagonal (linear in x): lam * (1 - 2*target) on each i in idxs
    - Off-diagonal quadratic terms: 2*lam on each (i,j), i<j in idxs
    Constant term dropped.
    """
    for i in idxs:
        Q[i, i] += lam * (1.0 - 2.0 * target)
    for a in range(len(idxs)):
        ia = idxs[a]
        for b in range(a + 1, len(idxs)):
            ib = idxs[b]
            Q[ia, ib] += 2.0 * lam
            Q[ib, ia] += 2.0 * lam

def build_qubo(H: np.ndarray,
               H_large: np.ndarray,
               L: int = 4,
               P_ap_W: float = 1.0,
               noise_W: float = 1e-9,
               lam_ap: float = 10.0,
               lam_user: float = 10.0,
               fairness_weights: Optional[np.ndarray] = None) -> np.ndarray:
    """
    Construct QUBO for AP-user link selection.
    - Diagonal: -w_k u_mk, u_mk = log2(1 + P_ap |h_mk|^2 / noise)
    - Off-diagonal: pairwise interference penalties via MRT-based projections
    - Penalties: AP capacity and user diversity (sum-equals constraints)
    """
    M, K = H.shape
    n = M * K
    idx = lambda m, k: m * K + k
    Q = np.zeros((n, n), dtype=float)

    # User weights for fairness
    if fairness_weights is None:
        weights = np.ones(K, dtype=float)
    else:
        weights = np.array(fairness_weights, dtype=float)
        if np.any(weights <= 0):
            raise ValueError("Fairness weights must be positive.")

    abs2 = np.abs(H) ** 2

    # Diagonal utilities
    for m in range(M):
        for k in range(K):
            snr_lin = (P_ap_W * abs2[m, k]) / noise_W
            u_mk = math.log2(1.0 + snr_lin)
            Q[idx(m, k), idx(m, k)] += -weights[k] * u_mk

    # Pairwise interference costs (across different users)
    for m in range(M):
        for k in range(K):
            i = idx(m, k)
            u_i = math.log2(1.0 + (P_ap_W * abs2[m, k]) / noise_W)
            for mp in range(m, M):
                for kp in range(K):
                    j = idx(mp, kp)
                    if j <= i:
                        continue
                    if k == kp:
                        continue  # ignore same-user pairs here
                    u_j = math.log2(1.0 + (P_ap_W * abs2[mp, kp]) / noise_W)
                    interf_on_k = P_ap_W * abs2[mp, k]
                    r_i = math.log2(1.0 + (P_ap_W * abs2[m, k]) / (noise_W + interf_on_k))
                    interf_on_kp = P_ap_W * abs2[m, kp]
                    r_j = math.log2(1.0 + (P_ap_W * abs2[mp, kp]) / (noise_W + interf_on_kp))
                    pen = max(0.0, (u_i + u_j) - (r_i + r_j))
                    if pen > 0.0:
                        Q[i, j] += pen
                        Q[j, i] += pen

    # AP capacity: at most one user per AP
    for m in range(M):
        idxs = [idx(m, k) for k in range(K)]
        add_sum_equals_penalty(Q, idxs, target=1, lam=lam_ap)

    # Per-user diversity: exactly L APs per user
    for k in range(K):
        idxs = [idx(m, k) for m in range(M)]
        add_sum_equals_penalty(Q, idxs, target=L, lam=lam_user)

    return Q

# -------------------- QUBO Solver (Simulated Annealing) --------------------

def qubo_energy(Q: np.ndarray, x: np.ndarray) -> float:
    return float(x @ (Q @ x))

def simulated_anneal_qubo(Q: np.ndarray,
                          steps: int = 2000,
                          T0: float = 5.0,
                          T1: float = 0.1,
                          seed: int = 0) -> np.ndarray:
    """
    Simple simulated annealing over binary x in {0,1}^n for QUBO.
    """
    seed_all(seed)
    n = Q.shape[0]
    x = np.random.randint(0, 2, size=n).astype(np.int8)
    for t in range(steps):
        T = T0 * (T1 / T0) ** (t / max(1, steps - 1))
        for _ in range(n):
            i = np.random.randint(0, n)
            xi = x[i]
            s = Q[i, i]
            if i > 0:
                s += 2.0 * float(np.dot(Q[i, :i], x[:i]))
            if i + 1 < n:
                s += 2.0 * float(np.dot(Q[i, i + 1:], x[i + 1:]))
            dE = (1 - 2 * xi) * s
            if dE < 0 or np.random.rand() < math.exp(-dE / max(T, 1e-12)):
                x[i] = 1 - xi
    return x

# -------------------- Feasibility Projection --------------------

def project_feasible(H: np.ndarray, A: np.ndarray, L: int) -> np.ndarray:
    """
    Enforce: per AP, <=1 user; per user, == L APs.
    - For AP rows with multiple 1s, keep the strongest |h_{mk}|^2 and clear others.
    - For users with fewer than L APs, add best available APs (by |h_{mk}|^2) not yet assigned.
    """
    M, K = H.shape
    A = A.copy().astype(int)

    # Per-AP capacity
    for m in range(M):
        if A[m, :].sum() > 1:
            strengths = np.abs(H[m, :]) ** 2
            k_star = int(np.argmax(strengths))
            A[m, :] = 0
            A[m, k_star] = 1

    # Per-user exact L APs
    # Build list of idle APs
    ap_idle = [m for m in range(M) if A[m, :].sum() == 0]
    for k in range(K):
        cur = int(A[:, k].sum())
        if cur < L:
            # rank idle APs for user k
            strengths = [(float(np.abs(H[m, k]) ** 2), m) for m in ap_idle]
            strengths.sort(reverse=True)
            needed = L - cur
            chosen = []
            for _, m in strengths:
                if needed == 0:
                    break
                A[m, k] = 1
                chosen.append(m)
                needed -= 1
            ap_idle = [m for m in ap_idle if m not in chosen]
    return A

# -------------------- Precoding and Evaluation --------------------

def rzf_precoder(H_A: np.ndarray, noise_W: float, P_ap_W: float = 1.0) -> np.ndarray:
    """
    Compute unnormalized RZF and return per-AP normalized W (row power = P_ap_W).
    """
    M, K = H_A.shape
    G = H_A.T  # K x M
    xi = noise_W
    W_un = G.conj().T @ np.linalg.pinv(G @ G.conj().T + xi * np.eye(K))
    W = np.zeros_like(W_un, dtype=complex)
    for m in range(M):
        row = W_un[m, :]
        norm2 = float(np.sum(np.abs(row) ** 2))
        if norm2 > 0.0:
            W[m, :] = row / np.sqrt(norm2) * np.sqrt(P_ap_W)
    return W

def evaluate_selection(H: np.ndarray,
                       A: np.ndarray,
                       noise_W: float,
                       P_ap_W: float = 1.0) -> Tuple[np.ndarray, np.ndarray]:
    """
    - Design RZF on masked H_A = H * A (Hadamard product)
    - Evaluate rates on the full physical channel H
    """
    H_A = H * A
    W = rzf_precoder(H_A, noise_W, P_ap_W=P_ap_W)
    M, K = H.shape
    rates = np.zeros(K)
    G_true = H.T  # K x M
    for k in range(K):
        hk = G_true[k, :]
        sig = float(np.abs(hk @ W[:, k]) ** 2)
        interf = 0.0
        for j in range(K):
            if j == k:
                continue
            interf += float(np.abs(hk @ W[:, j]) ** 2)
        sinr = sig / (interf + noise_W)
        rates[k] = math.log2(1.0 + sinr)
    return rates, W

def jain_fairness(rates: np.ndarray) -> float:
    s = float(np.sum(rates))
    if s <= 1e-12:
        return 0.0
    return (s ** 2) / (len(rates) * float(np.sum(rates ** 2)))

# -------------------- QUBO Selection Wrapper --------------------

def solve_qubo_selection(H: np.ndarray,
                         H_large: np.ndarray,
                         L: int,
                         noise_W: float,
                         lam_ap: float = 10.0,
                         lam_user: float = 10.0,
                         steps: int = 2000,
                         P_ap_W: float = 1.0,
                         fairness: bool = False,
                         seed: int = 0) -> np.ndarray:
    """
    Build QUBO and solve via annealing; reshape to A and project to feasibility.
    """
    M, K = H.shape
    if fairness:
        avg_large = np.mean(H_large, axis=0) + 1e-16
        w = 1.0 / avg_large
        w = w * (K / float(np.sum(w)))  # normalize sum of weights to K
    else:
        w = np.ones(K)

    Q = build_qubo(H, H_large, L=L, P_ap_W=P_ap_W, noise_W=noise_W,
                   lam_ap=lam_ap, lam_user=lam_user, fairness_weights=w)
    x = simulated_anneal_qubo(Q, steps=steps, seed=seed)
    A = x.reshape(M, K)
    A = project_feasible(H, A, L)
    return A

# -------------------- Baselines --------------------

def baseline_random(H: np.ndarray, L: int) -> np.ndarray:
    M, K = H.shape
    A = np.zeros((M, K), dtype=int)
    ap_idle = set(range(M))
    # Assign L APs per user
    for k in range(K):
        choices = list(ap_idle)
        random.shuffle(choices)
        taken = 0
        for m in choices:
            if taken == L:
                break
            if A[m, :].sum() == 0:
                A[m, k] = 1
                ap_idle.remove(m)
                taken += 1
        if A[:, k].sum() < L:
            remaining = L - int(A[:, k].sum())
            strengths = sorted([(float(np.abs(H[m, k]) ** 2), m)
                                for m in range(M) if A[m, :].sum() == 0],
                               reverse=True)
            for _, m in strengths[:remaining]:
                A[m, k] = 1
                ap_idle.discard(m)
    A = project_feasible(H, A, L)
    return A

def baseline_max_cg(H: np.ndarray, L: int) -> np.ndarray:
    M, K = H.shape
    A = np.zeros((M, K), dtype=int)
    ap_idle = set(range(M))
    for k in range(K):
        strengths = sorted([(float(np.abs(H[m, k]) ** 2), m) for m in ap_idle],
                           reverse=True)
        for _, m in strengths[:L]:
            A[m, k] = 1
            ap_idle.discard(m)
    A = project_feasible(H, A, L)
    return A

def baseline_greedy(H: np.ndarray,
                    L: int,
                    objective: str = "sum-rate",
                    noise_W: float = 1e-9,
                    P_ap_W: float = 1.0) -> np.ndarray:
    M, K = H.shape
    A = np.zeros((M, K), dtype=int)
    for _ in range(K * L):
        candidates = []
        for m in range(M):
            if A[m, :].sum() != 0:
                continue
            for k in range(K):
                if A[:, k].sum() >= L:
                    continue
                candidates.append((m, k))
        if not candidates:
            break
        cur_rates, _ = evaluate_selection(H, A, noise_W, P_ap_W=P_ap_W)
        if objective == "sum-rate":
            cur_metric = float(np.sum(cur_rates))
        else:
            cur_metric = float(np.min(cur_rates)) if cur_rates.size > 0 else 0.0

        best_gain, best_link = -1e18, None
        for (m, k) in candidates:
            A[m, k] = 1
            rates_new, _ = evaluate_selection(H, A, noise_W, P_ap_W=P_ap_W)
            new_metric = float(np.sum(rates_new)) if objective == "sum-rate" else float(np.min(rates_new))
            gain = new_metric - cur_metric
            if gain > best_gain:
                best_gain = gain
                best_link = (m, k)
            A[m, k] = 0
        if best_link is None:
            break
        A[best_link[0], best_link[1]] = 1
    A = project_feasible(H, A, L)
    return A

def summarize_metrics(all_rates: list) -> Dict[str, float]:
    sums = np.array([float(np.sum(r)) for r in all_rates])
    fairs = np.array([jain_fairness(r) for r in all_rates])
    return {
        "sum_rate_mean": float(np.mean(sums)),
        "sum_rate_std": float(np.std(sums, ddof=1)),
        "fair_mean": float(np.mean(fairs)),
        "fair_std": float(np.std(fairs, ddof=1)),
    }

def paired_t_test(a: np.ndarray, b: np.ndarray) -> float:
    """
    Paired t-test p-value (two-sided) for arrays a and b (differences across seeds).
    """
    from scipy.stats import ttest_rel
    t, p = ttest_rel(a, b)
    return float(p)
