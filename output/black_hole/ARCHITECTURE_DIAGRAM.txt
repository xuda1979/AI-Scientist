DATA FLOW WITH CUSTOM CALLBACK:
--------------------------------

Your microscopic model (e.g., 4D_gravity_eft.py):

  def schwarzschild_kernel_step(S_prev, target_chi, rng):
      # 1. Load kernel from eq. 4.14 / App. F
      K_omega = load_schwarzschild_kernel(...)
      
      # 2. Build one-step influence functional
      influence = build_process_tensor(K_omega, time_step)
      
      # 3. Apply to current state
      state = singular_values_to_state(S_prev)
      new_state = apply_influence(influence, state)
      
      # 4. Extract new singular values
      s_vals = state_to_singular_values(new_state)
      return s_vals

Main script:

  import simulation
  from my_physics import schwarzschild_kernel_step
  
  # Register your physics
  simulation.set_physical_step_update(schwarzschild_kernel_step)
  
  # Run simulation - uses YOUR physics instead of Haar
  # python simulation.py --outdir . --steps 12 --num-runs 50

  main()
