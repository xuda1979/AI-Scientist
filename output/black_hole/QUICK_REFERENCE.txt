COMMON MISTAKES
---------------
1. Callback returns 2D array → Must be 1D
2. Callback doesn't handle target_chi → Engine will truncate, but better to respect it
3. Callback fails on edge cases (empty S_prev, target_chi=1, etc.)
4. Callback is deterministic but doesn't use rng → Results won't be reproducible
